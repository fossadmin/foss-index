Ubuntu is a Debian-based distribution from Canonical and one of the most
widely used Linux desktops. Long-term support releases like 26.04.1 LTS
arrive every two years and get five years of free security updates,
extendable with Ubuntu Pro (free for personal use on up to five machines).

Ubuntu is an aggregate work: every package is covered by its own license.
The installer's optional third-party software box adds proprietary
graphics drivers and extra media formats - tick it or skip it.

## Quick start

*Checked against the project's documentation on November 10, 2026.
Canonical's install tutorial is being refreshed for newer releases. We
have not run these steps ourselves.*

### Get the image

Download Ubuntu Desktop 26.04.1 LTS from
https://ubuntu.com/download/desktop (about 6 GB). The page lists the
requirements: a 2 GHz dual-core processor, 6 GB of RAM and 25 GB of disk
space.

### Write it to a USB stick

Canonical's tutorial uses balenaEtcher: select the ISO, select the USB
drive, flash. The stick is erased in the process; back up first.

### Try it, then install

Boot from the USB (often F12 for the boot menu). The live session lets you
try Ubuntu without installing; the installer offers erasing the disk or
installing alongside another OS, plus the optional third-party software
box.

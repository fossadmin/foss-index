Pinta is a small image editor with layers, selections, effects and drawing tools. It suits quick edits and drawing where [GIMP](/tools/gimp/) is more than you need.

The project's README says original Pinta code is MIT licensed. It also includes code from Paint.NET 3.36 under that project's MIT terms.

## Quick start

*Checked against the project's own documentation on November 9, 2026. We have not run these installs ourselves. Commands are copied from the project's pages, or from Flathub and Homebrew where the section says so.*

### Linux

The Pinta site lists Linux options. The Flathub package is verified by its publisher:

```bash
flatpak install flathub com.github.PintaProject.Pinta
```

### Windows and macOS

Download the installer from the [Pinta Project site](https://www.pinta-project.com/). On Windows, open the file and follow the wizard, as the [user guide](https://www.pinta-project.com/user-guide/start/) describes.

## First steps

- Open an image with **File > Open** or create one with **File > New**.
- Use the toolbox for selection, brushes, shapes and text. Layers work like in other editors.
- Save with **File > Save As** and pick a format such as PNG or JPEG.

Start from the [Pinta user guide](https://www.pinta-project.com/user-guide/firststepsoverview/).

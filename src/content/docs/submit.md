---
title: Submit a tool
description: Suggest an open-source tool for the index. A person reviews every submission before anything is listed.
---

Know a tool that belongs here? Suggestions are welcome. The index stays
small and curated on purpose, so nothing is listed automatically: a
person reviews each submission first.

## What to include

- **A link to the project.** Its website or source repository is enough
  to start.
- **The name and one line on what it does.** Plain words, the way you
  would describe it to a colleague.
- **The app or edition, if there is more than one.** Some projects use
  different licenses for the app, the server or a paid version. Tell us
  which part you mean.
- **A category, if one fits.** Not sure? Say so and we will place it.
- **Anything else worth knowing** (optional): who it suits, why you
  like it, what to watch out for.

## How to send it

Open an issue on the [index's GitLab
repository](https://gitlab.com/fossadmin/foss-index/-/issues/new) with
the details above. That route needs a GitLab account; if you would
rather not create one, use the [FOSSadmin contact
page](https://fossadmin.com/contact/) instead.

Comfortable editing the site? Merge requests are welcome too. Each
listing is one Markdown file under `src/content/docs/tools/`.

## What happens next

We check that the project is open source, maintained enough to
recommend, and useful to people who want to choose open-source software. Listing is
free and cannot be bought. If the tool goes in, its page links to the
project's own support channels so the people who rely on it can help
fund it.

This is a curated directory of open-source software: a selection of tools to run yourself, from self-hosted services to everyday desktop apps. It is not an automated scrape
of GitHub.

Each listing shows the things we want to know before adopting a tool:

- **Its license**, so you can tell permissive (MIT, Apache-2.0) from
  copyleft (GPL, AGPL) at a glance.
- **Its recorded release and changelog**, refreshed by the included updater for
  projects hosted on GitHub. GIMP, digiKam, Blender and Forgejo are hosted
  elsewhere; their versions are checked by hand against the projects' own
  release pages.
- **A direct way to support the maintainers**, because open source stays
  alive when the people who rely on it fund it. See
  [how the funding works](/funding/).

We run [FOSSadmin](https://fossadmin.com), where we host and maintain
open-source software for small businesses. This index is part field guide,
part answer to a question the community keeps asking: how do you actually
pay for open source? One honest answer is to pay the people who support it,
and to make it easy for users to fund the projects they depend on.

Two small helpers run entirely in your browser: **Surprise me** opens a random tool's page, and the bookmark button keeps a shortlist in this browser's local storage. No account, and nothing is sent anywhere.

## How are tools chosen?

By a person, not a scrape. The list mixes tools we run or test ourselves
with reader suggestions, and every submission is reviewed before it goes
in. The index is a starting point, not a ranking.

## What does "open source" mean here?

We list a project only when the part we describe is under a license that
meets the open-source definition, and each page names that license. Some
projects mix licenses or editions: an app and its server may use different
licenses, a product may sell paid plans, or a program may bundle components
under other terms. When that applies, the page says which part is covered.
A project that is free to use but does not publish its source does not
qualify.

## Does a listing mean you have tested the tool?

No. A listing means the project looked worth a closer look, not that we
audited the code or run it everywhere. Each screenshot caption says
where the image comes from: our own test install (marked as such, with
fictional demo data) or the project's official material. Quick-start
snippets and install notes come from each project's own documentation, and the page says
so when we have not executed them. Read the license and the project's
own docs before committing to anything.

## Do you use AI on this project?

AI assistants do much of the coding, research and writing on this project,
under our direction. We remain responsible for what we publish, including
correcting mistakes.

A listing is a starting point, not an audit or a claim that we've
personally tested the tool. Screenshot captions identify their sources,
and quick-start notes say when we haven't run the instructions ourselves.

## Can a listing be bought?

No. Listings are editorial and free. When sponsorship opens it will buy
a clearly labeled placement, never a listing, a review or a category
position. [How the money side works](/funding/).

## How will sponsored placements be labeled?

Always as Sponsored, kept separate from the directory listings, one
sponsor at a time. The details live on the [sponsor page](/sponsor/).

## Who runs the index?

[FOSSadmin](https://fossadmin.com), an IT practice built on open source.
The index is a field guide for people who run their own software, and the tool pages say when
managed hosting is available.

## What about privacy here?

No accounts. The bookmark feature keeps your shortlist in this browser's
local storage only; nothing is sent anywhere from it.

We do run minimal, cookie-free analytics (hosted [Umami](https://umami.is))
to count visits in aggregate, mainly so potential sponsors can see the
index is used. For each page view it records the page address with query
strings and fragments stripped, the referring site stripped the same way,
browser, operating system, device type, screen size, language, and an
approximate location (country, region or city derived from your IP
address; the IP itself is not stored in the analytics records). An
anonymous session ID with a monthly-rotating salt groups page views
without cookies. If your browser sends Do Not Track, nothing is counted.

It does not follow you across other sites, no advertising or cross-site
profiles are built, and it never sees your saved tools; those live only in
your browser. Records are kept for 6 months on Umami's hosted service
(US region) and are used only as aggregate counts. Nothing is
sold, and no per-person data is shared.

# Screenshot credits and license notices

The tool pages mostly show each project's own published screenshots; the
rest are our own captures, and each entry below says which it is and
exactly what was changed for that image. All images are self-hosted here
so no third-party requests are made when you browse. Each entry records
its image's source and the license or permission terms available for it;
full license texts are in the `licenses/` folder next to this file.
Captions on each page link back to the exact source file at a pinned
commit. Unless an entry's Changes line says otherwise, an image was only
resized and recompressed to WebP; any cropping or other edit is stated
in that entry.

These six images are screenshots we took ourselves of fresh, local test
installs of each open-source release, run only to make the picture. They
show test states with no user data or third-party media: Grafana
uses synthetic data from its built-in TestData source, Radicale, Gotify,
Syncthing and Audiobookshelf show clearly fictional sample data we created
(covers drawn by us, audio synthesized locally), and Caddy shows its own
default welcome page. They were resized and recompressed to WebP only. Running an app for a
screenshot is not a production review of it.
